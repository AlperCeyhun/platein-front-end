# Tabaq web app
a web app to track dietary progress and meals.

to run the development server:

```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
- [Next.js Documentation](https://nextjs.org/docs)

## Branch Information

- **main**  
  Contains mockup pages only, without API calls. Use this branch if you want to see the UI without backend integration.

- **feature/spring_boot**  
  Contains API calls and the newest version of the app. Use this branch for the latest features and full backend connectivity.
